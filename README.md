# chat_priortisor
what if your 100 unread chats can be summerised and can be shown to you in a compact way??

so basically i have created an app called chat priortiser in which if there will be many unread messages then that app will analyse those chats and then priortise them on the basis of there importance so that you dont have to read all those unread chats.

everyone can make this app but what is special in it is i have made it in a 3-d way in the form of solar system so that it wont look like the normal applications and the user can have a better experience while using this app.

now in this app there is a use of gemini api key which will priortise the chats according to it and show you on the display like
1. the red planets in the app are the most important messages.
2. the yellow planets ae the less important messages.
3. the blue planets are the normal messages.
4. the green moons are those people who have mentioned you.
5. and all the asteroids roaming around are the nonsence messages.
